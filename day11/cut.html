The Cut workbench

📄 Design doc
Continuity · the deterministic half

Paste a Cut. Get it priced, checked, and turned into ten payloads.

Ten agents review a video before it is rendered. This page is the part between them that is not an agent: it validates the Cut against the schema, recomputes every cost from a fixed price book, builds the paste-ready payload for each node, and merges the findings back through an authority table you can read.

The Cut

2

Cost worksheet

recomputed — the authored numbers are not trusted
Why this is printed rather than hidden. The three lenses that check numbers run on a language model. Handing them a finished worksheet turns their job from doing arithmetic into checking arithmetic that is already on the page — which is a much easier job, and one you can audit yourself by reading the same lines.
3

Payloads

one per node · paste into MindPal
MindPal's Public API is behind a paywall, so this hop is manual: copy each payload into its node, run the workflow, then bring the six lens outputs back to step 4. Check every @variable renders purple before you run — a hand-typed reference does not bind, and the run fails without telling you.
4

Merge the findings

contract check → authority table → gate report
What this page is not. It is not a lens — it makes no judgement about the video. It validates, it does arithmetic, and it applies a lookup table. Every judgement in Continuity is made by one of the ten agents. The gate report below is what the authority table says should happen; node N10 says what it decided. If the two differ, that is a finding about the Checker.
